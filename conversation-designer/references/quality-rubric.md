# Conversation quality rubric

Evaluate observable behavior, not a required sequence or particular wording.

- **Continuity:** A new agent can identify the unresolved question, the user's objection, and a useful resume point without repeating the introduction.
- **Attribution:** User hypotheses, agent explanations, evidence, and agreement remain distinct. Discussing an explanation never becomes a claim of demonstrated understanding.
- **Curiosity:** The conversation answers directly and permits branches, pauses, disagreement, and return. No required drill, stage progression, completion target, or closing question appears.
- **Compression:** State captures position; memory captures durable meaning. Neither grows into a transcript. Important objections survive compaction and hypothesis revision.
- **Honesty:** Missing context remains missing. Unsettled explanations remain unsettled. Sources and confidence remain attached where they affect interpretation.
- **Operation boundaries:** Design does not start the inquiry. Review and summary do not write. Checkpoint does not answer the outstanding question. Resume yields after one turn and verifies continuity writes or supplies handoffs.

## Behavioral acceptance scenarios

Use synthetic fixtures rather than claiming access to Victor's original discussion.

1. The user proposes that choruses rise; an agent suggests increased intensity; the user objects that a chorus can descend. Resume the inquiry about function while retaining that objection and treating the explanation as a proposal. Do not invent a song or say the user has understood the explanation.
2. The user branches into lyrical repetition, then returns to melodic direction. Preserve the parked question and incorporate the new message without enforcing the old resume point.
3. A later counterexample weakens an earlier hypothesis. Update its qualification and retain the reason for revision; do not erase the objection or declare universal agreement.
4. Only a summary of prior discussion exists. Preserve its limits and ask for a missing example only if needed to answer; do not reconstruct a transcript.
5. Summarize or review a package. Verify canonical files remain unchanged and no new conversational turn is performed.
6. Checkpoint supplied notes. Update continuity without resolving their open question.
7. Resume without write access. Respond normally, then return complete state and memory handoffs without claiming they were saved.

Structural tests establish file-contract validity only. Behavioral evaluation requires inspecting a response and the resulting continuity against these criteria.
